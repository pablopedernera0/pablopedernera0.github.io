Cloud Foundations en verano

AWS Academy Cloud Foundations es el curso introductorio oficial de AWS: qué es la nube, los servicios principales de AWS, seguridad, arquitectura y precios. Lo abrimos para estudiantes y egresados del Terciario Urquiza de cualquier carrera, y también para sus docentes. Es gratis, se cursa en línea y a tu ritmo, y si aprobás te llevás la insignia oficial AWS Academy Graduate.

Qué te llevás

  • La insignia AWS Academy Graduate – Cloud Foundations en Credly, para sumar al CV y a LinkedIn. Se obtiene con al menos el 70 % en las evaluaciones del curso y se libera en la fecha de fin, el 26/2/2027.
  • Práctica en AWS real: los laboratorios se hacen en la consola de AWS, dentro de un entorno de AWS Academy. No hace falta tarjeta de crédito ni crear una cuenta de AWS.
  • La base para la certificación AWS Certified Cloud Practitioner (CLF-C02). Ojo: el examen de certificación es aparte y pago, y se rinde por tu cuenta. El curso no lo incluye.

Cómo se cursa

El curso está en el Canvas de AWS Academy: unos diez módulos, cada uno con su material, laboratorios guiados y una evaluación que se corrige sola. No hay entregas para el profesor. Vos manejás tus tiempos dentro de las fechas de la cursada.

Requisitos

  • Ser estudiante, egresado o docente del Terciario Urquiza (cualquier carrera y año).
  • Tener 18 años o más: lo exige AWS Academy.
  • Inscribirte con un correo al que tengas acceso, institucional (@terciariourquiza.edu.ar) o personal. Si egresaste, el institucional puede darse de baja, así que conviene usar el personal. Ese correo pasa a ser tu usuario de AWS Academy y no se puede cambiar. Si ya tenés cuenta (por ejemplo, del Learner Lab), usá el mismo correo: el curso aparece en la misma cuenta.
  • Una computadora con navegador. Los laboratorios no andan bien en el celular.

Si en el curso ves "Active su oferta de AWS Skill Builder", no la respondas todavía. Es una sola pregunta, se puede responder una sola vez y, si decís que sí, los 12 meses de Skill Builder empiezan a correr ese día. Conviene guardarla para cuando vayas a preparar la certificación. Consultalo en el encuentro.
