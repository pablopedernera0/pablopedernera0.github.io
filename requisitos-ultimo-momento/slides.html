Paso a paso · desde la web de GitHub

Los demás archivos, cualquier integrante

1

En el selector de branch (arriba a la izquierda, dice main), elegir cambios-20261009

2

Abrir el archivo, tocar el lápiz y hacer el cambio

3

Commit changes… dejando marcado Commit directly to the cambios-20261009 branch

Antes de editar, el selector tiene que decir cambios-20261009, no main. Y no la mezclen con main: nada de merge.
