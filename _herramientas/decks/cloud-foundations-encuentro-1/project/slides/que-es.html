Qué es

El curso introductorio oficial de AWS

Es

  • Qué es la nube y los servicios principales de AWS
  • Laboratorios en la consola de AWS real
  • Gratis, en línea y a tu ritmo
  • Con insignia oficial si aprobás

No es

  • La certificación: el examen es aparte y pago
  • Una cuenta de AWS propia: no pide tarjeta
  • Una materia: no hay entregas ni notas del profesor

Cloud Foundations · Verano 2026–2027

AWS Academy es el programa educativo de AWS para instituciones. El Terciario es miembro, y este es su curso de entrada. Remarcar lo que NO es: no es la certificación Cloud Practitioner (se ve al final) y no es una cuenta de AWS propia; los laboratorios se hacen en un entorno de AWS Academy que se abre y se cierra. Tampoco es una materia: las evaluaciones son de AWS y se corrigen solas.
