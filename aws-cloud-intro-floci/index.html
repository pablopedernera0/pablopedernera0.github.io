¿Qué es la computación en la nube?

Es la entrega de recursos de cómputo — servidores, almacenamiento, bases de datos, redes — a demanda, a través de Internet, con pago por uso.

⚡

Elasticidad

Escalás recursos hacia arriba o abajo según la demanda, en minutos.

💳

Pago por uso

Pagás solo lo que consumís, sin comprar hardware por adelantado.

🌍

Acceso global

Los recursos están disponibles desde cualquier lugar con Internet.

🛠️

Autoservicio

Aprovisionás recursos vos mismo, sin pedirle nada a un técnico de datacenter.

Antes: comprabas un servidor físico y esperabas semanas. Ahora: creás uno con un click o un comando.

■ Lo administrás vos    ■ Lo administra el proveedor

Amazon Web Services (AWS)

El proveedor cloud más grande del mundo — más de 200 servicios, presencia en decenas de países.

🌐

Regiones

Ubicaciones geográficas independientes (ej: us-east-1, sa-east-1).

🏢

Zonas de disponibilidad

Datacenters físicamente separados dentro de una región, para tolerancia a fallos.

📦

Servicios administrados

AWS se encarga del mantenimiento, backups y escalado de la infraestructura base.

🎯

Pagás lo que usás

Sin contratos largos — facturación por segundo, GB o request según el servicio.

Categorías principales de servicios

🖥️

Compute

EC2, Lambda — poder de procesamiento (máquinas virtuales, funciones serverless).

💾

Storage

S3, EBS — almacenamiento de archivos, objetos y discos.

🗄️

Database

RDS, DynamoDB — bases de datos relacionales y NoSQL administradas.

🌐

Networking

VPC, Route 53 — redes privadas virtuales y DNS.

🔐

Security & Identity

IAM — quién puede acceder a qué recurso y con qué permisos.

📊

Monitoring

CloudWatch — métricas, logs y alarmas de toda la infraestructura.

Hoy nos enfocamos en dos: Storage (S3) y Security (IAM).

💾 S3 — Simple Storage Service

El servicio de almacenamiento de objetos más usado de la industria: imágenes, documentos, backups, videos, logs.

🪣

Bucket

Un contenedor de nivel superior donde se guardan los objetos. El nombre debe ser único a nivel global.

📄

Object

El archivo en sí, junto con sus metadatos. Puede pesar desde bytes hasta terabytes.

🔑

Key

El identificador único del objeto dentro del bucket. No hay carpetas reales — todo es una key con forma de ruta.

🔗

URL

Cada objeto puede tener una URL pública o firmada para acceder desde el navegador.

En la práctica vamos a crear el bucket fotos-alumnos y subir imágenes a través de una app web.

🔐 IAM — Identity and Access Management

El sistema de identidades de AWS: controla quién puede hacer qué sobre qué recursos.

👤

Usuarios

Identidades individuales — personas o aplicaciones — con credenciales propias.

🎭

Roles

Identidades temporales que puede asumir un usuario o servicio, sin credenciales fijas.

📜

Políticas

Documentos JSON que definen permisos: qué acciones están permitidas sobre qué recursos.

🔑

Access Keys

AWS_ACCESS_KEY_ID + AWS_SECRET_ACCESS_KEY — las credenciales que usa una app para autenticarse.

Principio clave: mínimo privilegio — dar solo los permisos estrictamente necesarios.

¿Por qué practicar con un emulador?

Floci es un emulador de AWS de código abierto: simula S3 e IAM usando exactamente la misma API que AWS real.

💳

Sin tarjeta de crédito

No hace falta una cuenta AWS real ni riesgo de facturación inesperada.

🧪

Sandbox seguro

Podés romper y recrear todo cuantas veces quieras sin consecuencias.

🔁

API idéntica

Los comandos de AWS CLI y el código con boto3 funcionan igual en Floci que en AWS real.

🎓

Conocimiento transferible

Lo que aprendés hoy se aplica directamente el día que trabajes con una cuenta de AWS en producción.
