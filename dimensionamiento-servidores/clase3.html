¿Qué es el TTFB?

Time To First Byte: el tiempo que pasa desde que se pide una página hasta que llega el primer byte de la respuesta.

  • Incluye la conexión de red, pero sobre todo el tiempo que el servidor tarda en procesar el pedido
  • Un TTFB alto suele señalar un servidor lento (consultas pesadas a la base, poco CPU) — no un problema de la red del usuario
  • Es una de las métricas que un Analista Funcional usa para justificar si hace falta más CPU, o una base de datos mejor dimensionada

HTML completo vs. JSON, y la compresión

Página HTML completa

El servidor arma toda la estructura visual en cada pedido. Pesa mucho, pero comprime muy bien con gzip.

Backend JSON

Solo viajan datos. Ya pesa poco de entrada — la compresión casi no cambia el número.
