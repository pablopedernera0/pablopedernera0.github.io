🆓 Alternativas gratuitas a Claude Code

Un asistente de terminal tipo agente, sin costo — probadas en serio, no solo leídas de la documentación

¿Qué buscamos?

A lo largo de la materia viste cómo un asistente agéntico — que no solo chatea, sino que lee archivos, los edita y corre comandos por su cuenta — puede acelerar mucho el trabajo técnico.

Claude Code es una opción paga. Esta página junta alternativas gratuitas que probamos de verdad — instalando, corriendo y, en varios casos, encontrando problemas reales que la documentación no menciona.

Opción principal: GitHub Copilot para estudiantes

🎓

Gratis, verificando que sos estudiante

GitHub Education reabrió el plan gratuito para estudiantes en 2026: completions ilimitadas + 200 créditos mensuales para chat y modo agente.

🤖

CLI agéntica, ya estable

GitHub Copilot CLI llegó a disponibilidad general en febrero 2026 — terminal, no solo el editor: planifica, edita archivos y corre comandos.

💳

Sin tarjeta

El plan estudiante no pide método de pago — solo verificar tu condición de estudiante.

Cómo verificarte

1
Entrá a GitHub Education con tu cuenta de GitHub (creá una si no tenés).
2
Seguí el flujo de verificación de estudiante — suele pedir alguna prueba de inscripción (mail institucional, carnet, o similar).
3
Una vez aprobado, activás el plan Copilot Student desde tu cuenta.
4
Instalás la CLI (el método exacto cambia — brew install --cask copilot-cli en Mac, revisá la doc oficial para Linux/Windows) y hacés login.

No probamos nosotros el flujo de verificación completo (necesita tu identidad real) — si te trabás en algún paso, avisale al docente.

Sin verificación: OpenCode

Agente de código abierto para terminal, con la misma idea que Claude Code — lee tu proyecto, edita archivos, corre comandos — pero vos elegís qué modelo usar por detrás, entre más de 70 proveedores distintos (incluidos modelos locales).

🔓

100% código abierto

Sin costo de licencia — el único costo posible es el del modelo que elijas conectar.

🔌

Flexible

Podés apuntarlo a un modelo local (siguiente slide) para no depender de ninguna cuenta.

Cero cuenta: Ollama + modelo local

Corre el modelo en tu propia máquina, sin login, sin API key, sin tarjeta — nada sale de tu computadora.

El costo lo paga tu hardware: los modelos ocupan varios GB de disco, y sin una placa de video decente las respuestas tardan más. No es la opción más rápida, pero es la única que no depende de ninguna cuenta externa.

Lo que encontramos probándolo en serio

Instalamos Ollama + Aider en un contenedor Docker y probamos pedirle una edición real de código con dos tamaños de modelo.

Conclusión real, no de manual: para edición de código confiable con Aider, necesitás un modelo de al menos ~7B de parámetros. Los modelos "livianos" (1-2B, pensados para notebooks sin GPU) no alcanzan para tareas agénticas — sirven para autocompletado simple, no para que edite archivos solo.

Más fácil: Open WebUI (sin terminal)

El mismo repo Docker que instala Ollama suma Open WebUI: una interfaz de chat en el navegador, tipo ChatGPT, para hablar con el modelo local sin tocar la terminal.

1
Cloná el repo de infraestructura y levantalo con docker compose up -d --build (el mismo que usa Ollama + Aider).
2
Bajá un modelo (mínimo 7B, como en la slide anterior): docker compose exec ollama ollama pull qwen2.5-coder:7b.
3
Abrí http://localhost:3000 — entrás directo, sin crear cuenta ni loguearte.
4
Elegís el modelo que bajaste y chateás.

Es una interfaz de chat, no de edición: sirve para probar el modelo y para preguntas puntuales de código, pero no toca los archivos de tu proyecto — para eso seguís necesitando Aider (slide anterior). Y como corre por CPU sin placa de video potente, cada respuesta con un modelo de 7B puede tardar uno o varios minutos — no es que se cuelgue, es CPU-only.

Otras herramientas "traé tu propio modelo"

✍️

Aider

La que probamos arriba — mucha integración con Git, arma un commit por cada cambio.

🐳

OpenHands

Agente más autónomo, corre en su propio contenedor Docker con interfaz web.

🧩

Continue / Cline

Extensiones de VS Code, no de terminal, pero gratis y agénticas igual.

Las tres aceptan la misma lógica: modelo local con Ollama, o una capa gratuita de algún proveedor.

Opción secundaria: Gemini CLI

Es de Google, de código abierto, y funciona muy parecido a Claude Code. En teoría es gratis con solo una cuenta de Google, sin tarjeta.

En la práctica, probándolo, no fue tan simple. Con dos cuentas distintas (institucional y personal) nos encontramos con "permission denied" al generar la key — un problema conocido y reportado en el foro oficial de Google: cuentas nuevas quedan marcadas con cuota en cero hasta agregar una tarjeta en aistudio.google.com/billing (no te cobra dentro de la capa gratuita, pero la pide como verificación).

Puede que a vos te ande directo — pero si te encontrás con el mismo error, ya sabés que no es un problema tuyo ni nuestro.
