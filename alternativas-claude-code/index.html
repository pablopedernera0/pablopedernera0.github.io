🆓 Alternativas gratuitas a Claude Code

Un asistente de terminal tipo agente, sin costo

¿Qué buscamos?

A lo largo de la materia viste cómo un asistente agéntico — que no solo chatea, sino que lee archivos, los edita y corre comandos por su cuenta — puede acelerar mucho el trabajo técnico.

Claude Code es una opción paga. Esta página junta alternativas gratuitas para que puedas seguir practicando ese flujo de trabajo sin gastar nada.

Opción principal: Gemini CLI

🆓

Gratis con una cuenta de Google

No pide tarjeta — solo una cuenta de Google normal.

🔓

Código abierto

Mantenido por Google, con el código disponible públicamente.

🤖

Agéntico, en terminal

Funciona muy parecido a Claude Code: lee y edita archivos, corre comandos, todo desde la línea de comandos.

Para usarlo en tu máquina

La forma normal de entrar es hacer login con tu cuenta de Google — se abre el navegador, iniciás sesión, y listo. Igual de simple que loguearte en cualquier servicio de Google.

Para instalarlo y arrancar la primera vez, seguí la documentación oficial de Gemini CLI — la forma exacta de instalación cambia con el tiempo, conviene no depender de una captura vieja.

El problema si lo corrés en Docker

El login normal abre un navegador y espera que inicies sesión ahí — funciona bien en tu máquina, pero es incómodo (o directamente imposible) dentro de un contenedor headless, sin interfaz gráfica ni navegador.

Si estuviste siguiendo el hilo conductor de redes, es el mismo tipo de problema que resolvimos con el contenedor toolbox: necesitás que el contenedor arranque y trabaje solo, sin esperar que alguien haga clic en algo.

La solución: API key en vez de login por navegador

1
Generá una API key gratuita en Google AI Studio (con la misma cuenta de Google).
2
Pasala como variable de entorno GEMINI_API_KEY al contenedor.
3
Con esa variable seteada, Gemini CLI no pide login por navegador — el contenedor queda no interactivo, listo para automatizar.
# idea general — confirmá los flags/imagen exactos contra la documentación oficial
docker run -e GEMINI_API_KEY="tu-api-key" -it <tu-imagen> gemini

Otras alternativas gratuitas

Gemini CLI no es la única opción. Estas herramientas son de código abierto y vos elegís qué modelo usar por detrás — podés apuntarlas a la misma API key gratuita de Gemini del paso anterior.

Aider

Asistente de programación en pareja, en terminal, con mucha integración con Git (arma commits automáticamente por cada cambio que hace).

🔓

Código abierto

La herramienta en sí es gratis — el costo depende del modelo que le conectes.

🔌

"Bring your own model"

Se lo podés apuntar a tu API key gratuita de Gemini, o a un modelo local.

OpenHands

Agente de código abierto más autónomo — pensado para tareas de varios pasos, no solo autocompletar. Corre él mismo dentro de un contenedor Docker.

🐳

Corre en Docker

Se levanta como su propio contenedor, con una interfaz web local.

🔌

Modelo configurable

También acepta la misma lógica de "traé tu propia API key" gratuita.

Continue y Cline (extensiones de VS Code)

No son de terminal, pero son gratis, de código abierto, y bastante agénticas — leen y editan archivos del proyecto, y pueden correr comandos con tu permiso.

Buena opción si preferís quedarte en VS Code en vez de la línea de comandos. Igual que las anteriores, elegís qué modelo conectar por detrás.

Un caso aparte: GitHub Copilot gratis

GitHub ofrece Copilot gratis a estudiantes verificados a través de GitHub Education (GitHub Student Developer Pack).

Es un caso distinto a los anteriores: no es "gratis para cualquiera" como Gemini CLI, requiere verificar que sos estudiante. Vale la pena mencionarlo porque la mayoría de la clase ya califica.

Para arrancar

Si nunca usaste ninguna: empezá por Gemini CLI — es la más parecida a lo que ya venís usando con Claude Code, y no necesita más que una cuenta de Google.

Para repasar cómo escribir buenos prompts una vez que tengas la herramienta instalada, volvé a la serie IA aplicada.
